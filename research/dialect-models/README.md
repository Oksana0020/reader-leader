# Dialect model research lane

This folder is intentionally separate from the shipping demo. It contains ideas, notes, and experiments for custom accent handling, not the production-facing student flow.

## Scope

- Irish-English and Northern Irish variation sampling
- custom Vosk or downstream model adaptation experiments
- transcript error analysis for non-standard vowels and rhoticity
- data collection notes for future evaluation runs

## Keep out of the main demo path

The main app should continue to use the reliable local ASR + deterministic acceptance rules. This research folder is for longer-term investigation only.
